# Synergy AI Services



Учебный проект в рамках производственной практики — единый ИИ-сервис для Университета «Синергия», который объединяет пять решений для разных бизнес-процессов вуза. Всё работает как REST API на FastAPI: запускается локально, проверяется через Swagger UI.

Модули:

1. **Приёмная кампания** — чат-бот для абитуриентов и автоматическая оценка «горячести» лида по диалогу.
2. **Поддержка студентов** — RAG-ассистент, который отвечает на вопросы по учебным материалам (лекциям, методичкам), а не «из головы».
3. **Генерация контента** — создание черновиков тестовых заданий по фрагменту учебного текста.
4. **Аналитика** — предикция риска отчисления студента по данным о посещаемости, сданных заданиях и средней оценке.
5. **Админ-ассистент** — суммаризация документов и писем с извлечением действий и дедлайнов.

## Как устроено

Проект сделан без обучения собственных нейросетей с нуля. Для языковых задач (1, 2, 3, 5) используется готовая LLM через OpenAI-совместимый интерфейс, для аналитики (4) — классический `RandomForest` из `scikit-learn`. Это позволяет запустить всё на обычном ноутбуке без GPU.

Логика:
- LLM-модули обращаются к модели через единый клиент.
- RAG-модуль строит векторный индекс из материалов курса (`FAISS`) и подкладывает релевантные куски в контекст запроса.
- Модель риска обучается на CSV при первом запросе и кэшируется в памяти.
- Всё склеено через FastAPI: единая документация, валидация через Pydantic, изолированные роутеры.

Стек: Python 3.11+, FastAPI + Uvicorn, Pydantic v2 (+ `pydantic-settings`), LangChain + FAISS, scikit-learn + pandas, OpenAI SDK.
